# srender

Учебный проект — рисование на экране силами CPU, без GPU.

## Цель

Разобраться в том, как работает вывод графики на экран на низком уровне: как открыть окно, получить доступ к пиксельному буферу и нарисовать что угодно вручную, без видеокарты и графических API вроде OpenGL или Vulkan.

## Что происходит

- `winit` создаёт окно и обрабатывает события (мышь, клавиатура, оконные события)
- `softbuffer` предоставляет доступ к буферу пикселей окна — это просто `Vec<u32>`, куда можно писать цвета в формате `0xAARRGGBB`
- При каждой перерисовке (`RedrawRequested`) содержимое canvas-буфера копируется в softbuffer и выводится на экран

## Как запустить

```
cargo run
```

В открывшемся окне можно рисовать мышью, удерживая левую кнопку.

## Зависимости

| Крейт | Для чего |
|---|---|
| [`winit`](https://github.com/rust-windowing/winit) | Кроссплатформенное окно и event loop |
| [`softbuffer`](https://github.com/rust-windowing/softbuffer) | CPU-рендеринг: прямой доступ к пиксельному буферу окна |

## Ключевые идеи

**Пиксельный буфер** — это массив `u32`, где каждый элемент — цвет пикселя. Координата пикселя `(x, y)` соответствует индексу `y * width + x`.

**Цикл отрисовки** — `winit` не перерисовывает окно сам по себе. Нужно явно вызвать `window.request_redraw()`, после чего придёт событие `RedrawRequested`.
